# ML_JOM_2026
# DNN Surrogate Model for UHTS Prediction of Fe80Cr16Ni4 Nanocrystals

This repository contains the machine learning code associated with the paper:
"Effects of grain morphology and nanovoid characteristics on the tensile 
strength of Fe80Cr16Ni4 nanocrystals: An atomistic and machine learning study"

## Authors
Mahshad Fani, Oluwatimilehin Akinloye, Yingtao Liu, Shuozhi Xu
University of Oklahoma, 2026

## Requirements
- Python 3.8+
- PyTorch
- scikit-learn
- SHAP
- Optuna
- NumPy
- Pandas
- Matplotlib

## Usage
Run the script directly:
python dnn_uhts_Fe80Cr16Ni4.py
